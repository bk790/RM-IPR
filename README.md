# BRMK557 Research Methodology & IPR Flashcards

Static flashcard website for Assignment 1, organized into Modules 1–3.

## Deploy using your connected GitHub repository
1. Extract this ZIP.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the **root** of your `Flashcards` GitHub repository (not inside another nested folder).
3. Commit the changes to your production branch, usually `main`.
4. If Cloudflare Pages is connected to this repository, it should automatically deploy the new commit.
5. Cloudflare Pages build settings: Framework preset `None`; build command blank; build output directory `/` (root).

## Features
- 70+ revision cards organized by module
- Reveal answer, previous/next and shuffle
- Filters for all, known, need revision and not reviewed
- Browser-local progress tracking
- Responsive layout for mobile and desktop

Progress is stored in the student's own browser and is not centrally visible to a teacher.

The cards are concise revision prompts based on the supplied BRMK557 Assignment 1 and question-bank material. Use the question-bank answers for full 5-mark responses.
